# PMC-Agent 使用说明

## 快速开始

PMC-Agent面向制造业PMC计划员，查询BOM、核对库存和生产需求，提供图表解读与具体核实建议。

进入工作台后直接输入问题。智能查询推荐可以展开或收起；点击推荐后按发送提交。

## KQ-Z112 推荐体验

依次输入：

1. 查询KQ-Z112的BOM。
2. 生产54片可以吗？
3. 生产55片呢？
4. 为什么不能生产？
5. 查看来源。
6. 生产100片并生成采购清单。
7. 生产50片呢？
8. 帮我生成采购建议。

当前库存口径下，54片满足需求；55片时MAT-004需求1320片、库存1308片、缺口12片。100片有3项缺口；改为50片后采购建议使用新的50片需求。

## KQ-BHX3588M 推荐体验

1. 查询KQ-BHX3588M的BOM。
2. 看看库存。
3. 最多可以生产多少片？
4. 生产1片可以吗？
5. 生产100片呢？
6. 为什么不足？
7. 查看来源。

91项BOM需求均可计算，58项有可核算库存、33项库存未匹配。已核算物料的产量上限为38片。生产1片时已核算物料均满足；生产100片有5项已核实缺口。结果注明核算范围。

## 查看图表与AI解读

“需求 / 库存对比”按本次问题显示需求与库存；物料较多时可横向滚动。图表下方的AI分析解读包含核心结论、关键物料发现、生产计划影响和后续核实建议，其下为缺料清单。

展开“Agent执行过程”可查看本轮理解、核验、工具、计算及图表解读的实际状态。点击物料明细查看逐项数量，点击来源查看计算依据。

## 连续追问与历史

在同一产品会话中，可继续问“生产50片呢”“为什么不足”“查看来源”。输入另一产品编码会建立对应产品会话，原会话保存在左侧最近对话。

点击历史回答，右侧切换到该轮的明细和图表；刷新后恢复已保存的会话。最初的目录问答保存为“产品目录”。

## 数据状态与操作

- “库存未匹配”：该物料需求保留，库存数量为空。
- “重复记录待核实”：查看分项记录和来源。
- “问题解析请求失败”：重新发送本次问题。
- “AI解读未完成”：已算出的需求和库存仍可查看，重新发送可再次解读。
- 生产数量使用大于0的整数。0、负数、分数和不兼容单位会提示修正。
- 缺口排序按数量展示；补料安排结合库存、供应商交期和未交付订单核实。

DEMO-PMC-01的隔离测试能力保留在工程内，当前工作台以在线目录为准。
