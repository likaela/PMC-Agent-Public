# 工作台页面与状态设计

- 首页介绍制造业PMC计划助手，提供开始分析入口。
- 工作台包含产品选择、默认折叠的智能查询、聊天记录、当前回答结果及物料明细。
- `QueryComposer`负责自然语言输入；`MessageList`选择当前或历史回答。
- `SummaryCards`与`ResultPanel`按查询意图显示有数值的业务结果。
- `MaterialTable`展示对应回答的物料、单耗、库存、需求和差额；`SourceDetails`提供依据。
- `useAgent`统一真实HTTP、会话指针、产品切换、取消请求和历史恢复。
- `responseAdapter`只转换后端响应，不生成业务事实。

布局支持桌面与窄屏。表格在局部区域滚动，推荐问题收起后保留入口；每条消息与右侧结果使用同一响应对象。无事实、数量0、未知库存和请求错误采用不同状态，不伪装为生产成功。

正式业务输入由后端读取经过校验的公开数据包，浏览器不读取Excel或数据库。交互与信息层次遵循[业务展示规范](../../docs/business_result_presentation_rules.md)。
